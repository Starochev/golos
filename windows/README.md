# Голос для Windows

Порт голосового ввода с macOS. Распознавание идёт на этом компьютере,
на видеокарте через CUDA.

## Что общего с версией для macOS

Движок `whisper-server` и его HTTP-API, формат `config.json` (файл переносится
между машинами как есть), словарь с лимитом в 224 токена, замены готового
текста, детектор речи, очистка истории через час, схема вставки через буфер
обмена, жесты одной клавиши — удержание и двойной тап.

## Что пришлось решать иначе

**Правый Alt перехватывается насовсем.** На Windows одиночное нажатие Alt
отдаёт фокус меню активного окна — во время диктовки это сбивало бы всё
подряд. В русской и английской раскладках правый Alt ничего не набирает.

**Имена микрофонов обрезаны до 31 символа.** Это ограничение winmm, через
который идёт захват. «Desktop Microphone (Wireless PR» — так его видит система,
не приложение. Поэтому в конфиге хранится имя, а не номер: номера у звуковых
устройств перетасовываются при каждом подключении гарнитуры.

**Значок в трее прячется.** Windows кладёт все новые в скрытую область,
вытаскивается перетаскиванием. Пока не вытащил — настройки открываются
ключом `--settings`.

## Сборка

```
build:   %USERPROFILE%\.dotnet\dotnet.exe publish src -c Release -o app
запуск:  app\Golos.exe
```

Собирается на самой Windows: движок и рантайм под неё, кросс-сборки нет.

Нужен .NET 8 SDK. Ставится без прав администратора:

```
powershell -c "& ([scriptblock]::Create((irm https://dot.net/v1/dotnet-install.ps1))) -Channel 8.0"
```

Результат — один exe на ~155 МБ со встроенным рантаймом: на чужой машине
доустанавливать нечего.

## Движок и модели

Процессорная сборка whisper.cpp лежит внутри exe: `src/engine-cpu.zip`,
13 файлов и 10 МБ в распакованном виде. При первом запуске она раскладывается
в `Documents\Golos\engine`, и приложение работает сразу после скачивания.
Рядом кладётся метка с номером выпуска: после обновления содержимое
заменяется, иначе новый exe работал бы со старыми библиотеками.

Сборка под видеокарту весит больше полугигабайта, внутрь такое не положишь.
Она качается кнопкой в настройках и ложится в `Documents\Golos\engine-cuda`.
Нужен драйвер NVIDIA 12.x.

Порядок поиска движка в `EngineCatalog.Locate`: своя папка из настроек,
потом `engine-cuda`, потом папка `engine` рядом с exe, потом встроенная.

Модели качаются отдельно, при первом запуске, в `Documents\Golos\models`.
Если рядом с exe есть папка `models`, берётся она.

## Клавиша записи

Меняется в настройках. Список закрытый намеренно: свободный захват «нажми
любую клавишу» позволяет назначить букву — и человек остаётся без клавиатуры,
потому что каждое её нажатие уходит в диктовку.

Доступны правый Alt (по умолчанию), правый Windows, правый Ctrl, правый Shift
и F13–F16. Идентификаторы общие с версией для macOS: там та же физическая
клавиша называется правым Option, и конфиг переносится между машинами
без правок.

Модификаторы приложение проглатывает — иначе одиночное нажатие Alt отдаст
фокус меню активного окна. Обычные клавиши вроде F13 пропускаются дальше.

## Автозапуск

Галочка в настройках. Через ветку `Run` в реестре текущего пользователя:
прав администратора не требует и не оставляет следов в планировщике.

Путь записывается текущий. Перенёс приложение — переставь галочку; настройки
сами скажут, что записан устаревший путь.

## Иконка

Та же, что на macOS, собрана из тех же исходников в `icon/` в корне
репозитория. В `.ico` вложены семь размеров от 16 до 256, мелкие берутся
из упрощённого рисунка: тонкие лучи со свечением в 16 пикселях превращаются
в пятно.

Значок в трее рисуется отдельно и показывает состояние — он не из `.ico`.

## Известные грани

Значок в трее Windows прячет в скрытую область — вытаскивается перетаскиванием.

Имена микрофонов обрезаны до 31 символа: так их отдаёт winmm, через который
идёт захват.

## Обновления

Приложение читает `windows.json` из ветки `main` репозитория:

```json
{ "version": "0.2.0", "url": "https://github.com/.../Golos.exe", "sha256": "…", "notes": "…" }
```

Адрес взят из ветки, а не из «последнего релиза»: в том же репозитории лежат
сборки для macOS, и «последним» оказывался бы то один, то другой.

Себя на ходу приложение заменить не может — файл занят. Поэтому оно оставляет
помощника, который ждёт выхода процесса, подменяет exe и запускает заново.
Перед подменой проверяются размер, сигнатура MZ и контрольная сумма.

## Когда вместо текста приходит «Всем пока!»

Модель училась на субтитрах и при неудачном декодировании выдаёт оттуда
концовку ролика. Звук при этом нормальный: тот же файл со второй попытки
распознаётся верно, поэтому приложение просто переспрашивает.

Отдельно отсеиваются записи без речи — по числу окон со звуком, а не по пику:
пик всегда задран собственным сигналом старта.

## Почему длинная диктовка режется на куски

Whisper разбирает звук окнами по 30 секунд, и на стыке окон декодер срывается:
на записи в 47 секунд со словарём выходило 128 знаков вместо 757. Приложение
режет запись на куски по 22 секунды, выбирая самое тихое место для реза,
и склеивает результат.

## Диагностика

`%USERPROFILE%\Documents\Golos\golos.log` — запуск, список микрофонов,
распознанный текст, ошибки.
