# Голос

Голосовой ввод для macOS: держишь клавишу, диктуешь, текст сам оказывается
в активном поле. Распознавание идёт на твоём Маке — записи никуда не уходят.

Писалось ради одной задачи: **диктовать по-русски так, чтобы англицизмы
оставались латиницей.** Штатная диктовка macOS превращает «pull request»
в «пул реквест», «merge» в «мёрдж» и заставляет переключать раскладку руками.
Голос пишет их как надо.

Пример живого распознавания:

> Смотри, я задеплоил приложение на **Vercel**, но там в **pull request**
> сломался **CI**. Надо пофиксить билд и обновить **environment variables**,
> потом смержить в **main**.

## Что нужно

- Мак на Apple Silicon (M1 и новее), macOS 14 и выше
- 0.5–3 ГБ на диске под модель распознавания — качается при первом запуске

## Установка

Скачать `.dmg` из [релизов](https://github.com/Starochev/golos/releases),
перетащить «Голос» в Программы, запустить.

**Первый запуск покажет предупреждение** «macOS не может проверить приложение» —
у сборки нет платной подписи Apple. Обход: Системные настройки →
Конфиденциальность и безопасность → пролистать вниз → «Открыть всё равно».

Дальше приложение попросит два разрешения:

- **Микрофон** — система спросит сама.
- **Универсальный доступ** — добавить вручную: Системные настройки →
  Конфиденциальность и безопасность → Универсальный доступ → «+» → `Голос.app`.
  Без него не работают ни горячая клавиша, ни вставка. Перезапускать не нужно,
  приложение подхватит разрешение само.

Потом откроется выбор модели. Рекомендуемая — **Large v3**: лучшее качество
русского, и на современном Маке она всё равно быстрая, около секунды на
десять секунд речи.

## Как пользоваться

| Жест | Что происходит |
|---|---|
| Держать правый ⌥ | Пишет, пока держишь. Отпустил — распознал и вставил |
| Двойной тап по правому ⌥ | Запись до следующего тапа. Руки свободны |
| Escape во время записи | Отменить, ничего не вставлять |
| Одиночный короткий тап | Ничего. Случайное нажатие не считается |

Обычный набор с ⌥ (⌥+3 и подобное) запись отменяет — приложение понимает,
что ты печатаешь, а не диктуешь.

## Словарь — главный рычаг качества

`~/Documents/Golos/config.json`, перечитывается перед каждой диктовкой:
правку видно сразу, перезапуск не нужен.

| Ключ | Смысл |
|---|---|
| `vocabulary` | Термины, которые нужны латиницей. Смещают распознавание в нужную сторону |
| `replacements` | Замены по готовому тексту, если модель всё же промазала по имени |
| `insertMode` | `paste` (буфер + Cmd+V), `type` (набор посимвольно), `clipboard` (только в буфер) |
| `language` | `ru`, любой другой код или `auto` |
| `keepHistory` | Хранить wav и расшифровки в `~/Documents/Golos/history` |

Всё, что распознаётся транслитом, дописывай в `vocabulary`. Имена, которые
модель ломает стабильно, — в `replacements`.

**У словаря есть потолок:** подсказка модели ограничена 224 токенами, это
примерно 600 символов. Сверх этого приложение отрезает само и пишет в журнал,
сколько не влезло. Поэтому держи в списке только то, что иначе уйдёт
в транслит: русские слова модель и так пишет кириллицей.

## Как устроено

```
правый ⌥ (CGEventTap)
   ↓
AVAudioEngine → моно 16 кГц → WAV в памяти
   ↓
whisper.cpp внутри бандла, модель уже в памяти
   ↓
замены по словарю
   ↓
буфер обмена → Cmd+V → буфер восстановлен
```

Движок распознавания собран статически и лежит внутри приложения: Homebrew
и прочие зависимости не нужны. Он поднимается при старте и живёт всё время
работы — модель на несколько гигабайт грузится секунды, и делать это на
каждую фразу нельзя.

## Сборка из исходников

```bash
brew install cmake
./build-engine.sh     # собирает whisper.cpp статически, разово
./setup-signing.sh    # локальный сертификат, разово
./build.sh
open Golos.app
```

`setup-signing.sh` нужен, чтобы macOS узнавала приложение после пересборки
и не сбрасывала выданные разрешения. Без него подпись ad-hoc, и разрешение
придётся выдавать заново после каждой сборки.

Выпуск релиза:

```bash
./release.sh 1.1.0 --dry-run   # собрать локально
./release.sh 1.1.0             # собрать и выложить на GitHub
```

## Файлы

| Файл | Отвечает за |
|---|---|
| `Hotkey.swift` | Перехват правого ⌥, разбор жестов |
| `Recorder.swift` | Микрофон, конвертация в 16 кГц, сборка WAV |
| `Whisper.swift` | Запуск движка и запросы к нему |
| `Inserter.swift` | Вставка: буфер + Cmd+V, прямой набор, только буфер |
| `ModelManager.swift` | Каталог моделей и загрузка |
| `SetupWindow.swift` | Окно выбора модели |
| `Config.swift` | Конфиг и словарь |
| `Autostart.swift` | Запуск при входе в систему |
| `Updater.swift` | Автообновления через Sparkle |
| `Controller.swift` | Склейка всего перечисленного |
| `main.swift` | Иконка и меню в строке меню |

## Диагностика

`~/Documents/Golos/golos.log` — запуск, разрешения, распознанный текст, ошибки.
