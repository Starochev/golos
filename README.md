# Голос

Голосовой ввод для macOS: держишь клавишу, диктуешь, текст сам оказывается
в активном поле. Распознавание идёт на твоём Маке — записи никуда не уходят.

Писалось ради одной задачи: **диктовать по-русски так, чтобы англицизмы
оставались латиницей.** Штатная диктовка macOS превращает «pull request»
в «пул реквест», «merge» в «мёрдж» и заставляет переключать раскладку руками.
Голос пишет их как надо.

Пример живого распознавания:

> Смотри, я задеплоил приложение на **Vercel**, но там в **pull request**
> сломался **CI**. Надо пофиксить билд и обновить **environment variables**,
> потом смержить в **main**.

## Что нужно

- Мак на Apple Silicon (M1 и новее), macOS 14 и выше
- 0.5–3 ГБ на диске под модель распознавания — качается при первом запуске

## Установка

Скачать `.dmg` из [релизов](https://github.com/Starochev/golos/releases),
перетащить «Голос» в Программы, запустить.

**Первый запуск покажет предупреждение** «macOS не может проверить приложение» —
у сборки нет платной подписи Apple. Обход: Системные настройки →
Конфиденциальность и безопасность → пролистать вниз → «Открыть всё равно».

Дальше приложение попросит два разрешения:

- **Микрофон** — система спросит сама.
- **Универсальный доступ** — добавить вручную: Системные настройки →
  Конфиденциальность и безопасность → Универсальный доступ → «+» → `Голос.app`.
  Без него не работают ни горячая клавиша, ни вставка. Перезапускать не нужно,
  приложение подхватит разрешение само.

Потом откроется выбор модели. Рекомендуемая — **Large v3**: лучшее качество
русского, и на современном Маке она всё равно быстрая, около секунды на
десять секунд речи.

## Как пользоваться

| Жест | Что происходит |
|---|---|
| Держать клавишу записи | Пишет, пока держишь. Отпустил — распознал и вставил |
| Двойной тап по ней же | Запись до следующего тапа. Руки свободны |
| Escape во время записи | Отменить, ничего не вставлять |
| Одиночный короткий тап | Ничего. Случайное нажатие не считается |

Обычный набор с ⌥ (⌥+3 и подобное) запись отменяет — приложение понимает,
что ты печатаешь, а не диктуешь.

По умолчанию это правый ⌥. В настройках можно выбрать правый ⌘, правый ⌃,
правый ⇧ или F13–F16. Список закрытый намеренно: свободный захват позволил бы
назначить букву — и каждое её нажатие уходило бы в диктовку.

## Настройки

Меню в строке состояния → **Настройки…** (или ⌘,). Четыре вкладки:

**Основное** — окошко с волной, автозапуск при входе, сигналы записи,
хранение записей, куда девать готовый текст, язык речи и выбор модели.

Во время диктовки внизу экрана всплывает небольшая панель с живой формой
волны — видно, что тебя слышат. Фокус она не перехватывает, поэтому вставка
в активное поле работает как обычно. Отключается там же.

Цвет волны выбирается из пяти готовых — красный, бирюзовый, фиолетовый,
янтарный, монохром — либо задаётся свой. Один цвет красит и окошко, и иконку
в строке меню: разъезжаться им незачем. Рядом с палитрой живое превью.

Сигналов три на выбор — «Мягкий», «Колокольчик», «Тихий», с кнопкой
прослушивания. Тоны синтезируются в коде: системные Tink и Pop звучат как
отказ ввода, а для действия, которое повторяется десятки раз в день,
это раздражает.

Записи по умолчанию удаляются **через час**: история нужна, чтобы разобрать
свежую ошибку распознавания, а не копить голос на диске. Срок меняется там же,
вплоть до «не удалять».

**Словарь** — главный рычаг качества. Слова, которые распознавание должно
писать латиницей: `pull request`, `Vercel`, `merge`. Всё, что вылезает
транслитом, добавляй сюда.

У словаря есть потолок: подсказка модели ограничена 224 токенами, это около
600 символов. Полоска внизу вкладки показывает, сколько занято, и краснеет
при переполнении — молча обрезанный хвост словаря был бы худшим из сюрпризов.
Русские слова добавлять незачем, они и так пишутся кириллицей.

**Замены** — если распознавание стабильно ошибается на слове, впиши, что
слышится и чем это заменить. Применяется к готовому тексту, без учёта регистра.

**О программе** — версия, проверка обновлений, папка записей, журнал.

Кнопки «Сохранить» нет: настройки применяются сразу, приложение перечитывает
их перед каждой диктовкой.

### Для тех, кто любит текстом

Всё то же лежит в `~/Documents/Golos/config.json` и правится руками.

| Ключ | Смысл |
|---|---|
| `vocabulary` | Термины, которые нужны латиницей |
| `replacements` | Замены по готовому тексту |
| `insertMode` | `paste` (буфер + Cmd+V), `type` (набор посимвольно), `clipboard` (только в буфер) |
| `language` | `ru`, любой другой код или `auto` |
| `keepHistory` | Хранить wav и расшифровки в `~/Documents/Golos/history` |
| `historyRetentionHours` | Через сколько часов их удалять, `0` — никогда |
| `soundTheme` | `soft`, `bell` или `quiet` |
| `waveTheme` | `red`, `teal`, `violet`, `amber`, `mono` или `custom` |
| `customWaveColor` | Свой цвет в виде `#RRGGBB` |

## Как устроено

```
правый ⌥ (CGEventTap)
   ↓
AVAudioEngine → моно 16 кГц → WAV в памяти
   ↓
whisper.cpp внутри бандла, модель уже в памяти
   ↓
замены по словарю
   ↓
буфер обмена → Cmd+V → буфер восстановлен
```

Движок распознавания собран статически и лежит внутри приложения: Homebrew
и прочие зависимости не нужны. Он поднимается при старте и живёт всё время
работы — модель на несколько гигабайт грузится секунды, и делать это на
каждую фразу нельзя.

## Сборка из исходников

```bash
brew install cmake
./build-engine.sh     # собирает whisper.cpp статически, разово
./setup-signing.sh    # локальный сертификат, разово
./build.sh
open Golos.app
```

`setup-signing.sh` нужен, чтобы macOS узнавала приложение после пересборки
и не сбрасывала выданные разрешения. Без него подпись ad-hoc, и разрешение
придётся выдавать заново после каждой сборки.

Выпуск релиза:

```bash
./release.sh 1.1.0 --dry-run   # собрать локально
./release.sh 1.1.0             # собрать и выложить на GitHub
```

## Когда вместо текста приходит «Всем пока!»

Модель училась на субтитрах, и при неудачном декодировании выдаёт оттуда
частую фразу — концовку ролика. Звук при этом нормальный: тот же файл со
второй попытки распознаётся верно.

Приложение ловит такие фразы и переспрашивает один раз.

Совпадения ищутся по вхождению, а не целиком: модель приделывает приставки,
и первая версия правила пропустила «Всем спасибо за просмотр!», потому что
в списке было «спасибо за просмотр».

Решает не только список, но и плотность текста. Обычная речь идёт около десяти
знаков в секунду — замерено по полусотне живых записей; выдумка даёт полтора.
Поэтому «Спасибо за просмотр этого макета» на четырёх секундах проходит,
а «Спасибо за просмотр!» на шести — нет.

Подписи из субтитровых файлов вроде «Субтитры сделал DimaTorzok» помечаются
всегда: такое не диктуют.

Второй способ, которым лезут субтитры: основной текст распознан верно, а в
хвост приклеена концовка ролика — «…И смотри. Всем пока!». Плотность всего
текста при этом нормальная, и проверка по нему такое не видит.

Хвост ищется по словам, а не по предложениям: разделителя перед выдумкой может
не быть вовсе — «Как-то можно сделать, чтобы Спасибо за просмотр!». Срезаются
до шести последних слов, если они точно совпадают с заученной концовкой и до
них осталось хотя бы три слова.

Приветствия в этом списке тоже есть. «Всем привет» в начале речи законно,
а после двадцати секунд диктовки — уже нет, поэтому проверяется только хвост.

Отдельно отсеиваются записи без речи: считается, сколько стомиллисекундных
окон содержат звук громче примерно −42 дБ. Пик для этого не годится — своим
же сигналом старта он всегда задран.

## Почему длинная диктовка режется на куски

Whisper разбирает звук окнами по 30 секунд, и на стыке окон декодер срывается.
Замерено на живой записи в 47 секунд: со словарём выходило 128 знаков вместо
757, причём текст был не обрезан, а другой — модель выдавала обрывки начала
и конца. Без словаря та же запись распознавалась целиком, но словарь нужнее.

Зависимости от длины словаря нет: 57 знаков ломали, 197 — нет, 297 снова
ломали. Это не порог, а нестабильность. Поэтому приложение само режет запись
на куски по 22 секунды, выбирая самое тихое место для реза, и склеивает
результат.

## Диагностика

`~/Documents/Golos/golos.log` — запуск, разрешения, распознанный текст, ошибки.

## Иконка в строке меню

Показывает состояние: в покое ровная волна, во время записи полосы краснеют
и шевелятся в такт голосу, при распознавании по ним бежит серая волна.

В покое изображение шаблонное — система сама красит его под светлую и тёмную
строку меню и подсвечивает при открытом меню. Цветные состояния шаблонными
быть не могут: система перекрасила бы их в чёрный и потеряла смысл красного.

## Иконка приложения

Рисуется кодом, а не в редакторе: `icon/draw.swift` строит её через Core
Graphics, `icon/build-icon.sh` собирает `AppIcon.icns`.

Мелкие размеры берутся из упрощённых рисунков. Тонкие лучи и свечение,
которые красиво выглядят на 512 пикселях, в 16 превращаются в пятно, поэтому
для 16 и 32 нарисованы отдельные версии — крупнее зубцы, толще кольцо,
у самой мелкой свечения нет вовсе.

## Версия для Windows

Отдельная сборка на C#: [Голос для Windows 0.2.0](https://github.com/Starochev/golos/releases/tag/win-v0.2.0).
Один файл, ставить ничего не надо, распознавание идёт на видеокарте через CUDA.

Формат `config.json` общий — файл переносится между маком и компьютером как
есть, вместе со словарём и заменами. Правый ⌥ там называется правым Alt,
но это та же клавиша и тот же идентификатор в настройках.

Лента обновлений для неё — `windows.json` в этой ветке. Адрес взят из ветки,
а не из «последнего релиза»: здесь же лежат сборки для macOS, и «последним»
оказывался бы то один, то другой.
